プライバシーポリシー

このページは、「会社のなかみ図鑑」（以下「当チャンネル」）と、当チャンネルの運営者が使う投稿ツール「会社のなかみ図鑑 投稿」（以下「本ツール」）の、個人情報の取り扱いについて定めるものです。

1. 本ツールの性質

本ツールは、当チャンネルの運営者が自分の YouTube チャンネルへ動画を予約投稿し、再生数などの数字を確認するために使う、運営者専用のソフトウェアです。運営者以外の方が利用することはありません。

2. Google アカウントから取得する情報

本ツールは、運営者自身の Google アカウントの認可（OAuth）を受けて、次の範囲の情報だけを扱います。

  • 運営者の YouTube チャンネルへの動画のアップロード、タイトル・説明文・公開日時・サムネイルの設定、コメントの投稿（YouTube Data API）
  • 運営者の YouTube チャンネルの再生数・視聴維持率などの分析データの読み取り（YouTube Analytics API）
  • 運営者が管理する Google スプレッドシートの読み取り（Google Sheets API）

視聴者やコメントをくださった方の個人情報を、本ツールが収集・保存することはありません。

3. 情報の保管と利用

  • 認可のトークンは、運営者が管理するコンピュータの中にだけ保存し、第三者に渡しません。
  • 取得したデータは、当チャンネルの動画の投稿と、動画の改善のための分析にだけ使います。
  • 取得したデータを販売・共有・広告目的で利用することはありません。

4. Google API サービスのユーザーデータに関するポリシー

本ツールが Google API から受け取った情報の利用は、Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に従います。

5. 認可の取り消し

Google アカウントの「サードパーティ製のアプリとサービス」から、本ツールへの認可をいつでも取り消せます。

6. 当チャンネルの視聴について

当チャンネルの動画は YouTube と Instagram で公開しています。視聴時の情報の取り扱いは、それぞれのサービスのプライバシーポリシーに従います。当チャンネル自身が視聴者の個人情報を集めることはありません。

7. 改定

このポリシーは必要に応じて改定します。改定した場合は、このページで公開します。

8. お問い合わせ

当チャンネルの YouTube または Instagram のコメント・メッセージからご連絡ください。
